# D4 UA Localization: Content (Community Edition)

Український переклад і озвучення для Dungeons 4, включно з усіма DLC. Це репозиторій контенту: тут лише переклад і голоси. Застосунок (інсталятор і інструмент перекладача) лежить в окремому репозиторії [`d4loc-ua-tool`](https://github.com/vladmu/d4loc-ua-tool).

Проєкт неофіційний і не пов'язаний із правовласниками гри. Див. [`DISCLAIMER.md`](DISCLAIMER.md).

## Що де лежить

Репозиторій і є розпакованою українською мовою у тій самій структурі, з якою працює інструмент перекладача, без проміжних форматів:

| Шлях | Що це |
| --- | --- |
| `uk/loca_uk_texts.csv` | Переклад у форматі гри (`name, wording, voice, tags`), саме цей файл читає гра |
| `uk/audio/…` | Голоси за шляхами з бандлів гри (Ogg Opus 32 кбіт/с), разом з `audiodef.txt` і `audioindex.txt` |
| `uk/audio_metadata.csv` | Ключ репліки → бандл і шлях файлу |
| `uk/status.csv` | Ключ і статус рядка: `machine` (чернетка моделі), `edited` (вичитано), `copied` (взято з оригіналу), `user` (текст змінила людина), `recorded` (людина записала голос). Інструмент перекладача сам ставить `user` і `recorded` при збереженні; конвеєр рядки з цими позначками не перекладає й не озвучує заново |
| `uk/voice_state.csv` | Ключ і підпис параметрів, з якими рядок озвучено: за ним конвеєр знає, які голоси застаріли відносно тексту (його веде команда `voice`, вручну не правте) |
| `manifest.json` | Версія контенту, кількість голосів, версія гри, для якої зроблено контент |
| `toolcheck.json` | Штамп перевірки: контрольні суми файлів і застосунку (його записує інструмент) |

Англійського тексту й аудіо гри тут немає: вони належать правовласникам. Кожен бере їх зі своєї копії гри, інструмент розпаковує їх у теку `en/`, яка не потрапляє в git. Також інструмент створює в клоні `uk/pending/` (черга ще не збережених правок) і `source.json` (підпис файлів гри); вони теж не комітяться. Усі автоматично створювані теки й файли описано в [README застосунку](https://github.com/vladmu/d4loc-ua-tool#які-теки-й-файли-створює-застосунок-сам).

## Як запропонувати правку

1. Зробіть fork цього репозиторію й клонуйте його.
2. У застосунку [D4 UA Localization Toolkit](https://github.com/vladmu/d4loc-ua-tool/releases) відкрийте «Інструмент перекладача» й вкажіть клон як теку проєкту. Інструмент розпакує поряд англійську з вашої гри, і ви бачите оригінал і переклад поруч, можете слухати репліки, правити текст або записати власну репліку замість наявної.
3. Натисніть «Зберегти»: зміни записуються в `uk/` вашого клона (у гру інструмент нічого не пише), інструмент перевіряє переклад і записує `toolcheck.json`. Щоб одразу перевірити правку в грі, натисніть «Зберегти й встановити»: відкриється вікно інсталятора, і встановлення почнеться саме.
4. Зробіть commit і push (`git commit -s`), створіть pull request. Перевірка PR червона, доки штампа немає або файли змінено вже після нього.

Інструмент нічого не робить за вас у git: fork, clone, commit, push і pull request ви виконуєте самі.

Правила тексту: службову розмітку (`{attack:…}`, `<color=…>`, `<sprite …>`, `\n`) лишайте без змін; ремарки в діалогах у зірочках (`*зітхає*`); «ти» і «ви» узгоджуйте в межах репліки й сцени; уникайте русизмів і кальок: текст озвучується вголос.

Правила голосу: ви гарантуєте, що маєте права на запис (власний голос або явний дозвіл) і що він не імітує реальних людей. Нові записи інструмент сам кодує в Ogg Opus і кладе на місце старого файлу.

## Що змінюється в оригінальних файлах гри

Інсталятор додає в кожен наявний мовний файл гри (`loca_*_texts.csv`) один рядок `_languageName_uk,<назва української мови>,,`, щоб українська мова була в меню мов. Це обмеження, яке ми не знайшли як обійти; нічого іншого в оригінальних файлах не змінюється. Докладно: [README застосунку](https://github.com/vladmu/d4loc-ua-tool#що-змінюється-в-оригінальних-файлах-гри).

## Випуск контенту (для мейнтейнера)

Збірка виконується інструментами з репозиторію застосунку: `python dev/run.py sync`, `build`, `public`, `voice`, `toolcheck`, `release`, потім реліз на GitHub із трьома файлами з `release_assets/`: `manifest.json`, `loca_uk_texts.csv` (поряд, не запаковані) і `voice.zip` (голоси). Застосунок завжди бере останній реліз цього репозиторію.
